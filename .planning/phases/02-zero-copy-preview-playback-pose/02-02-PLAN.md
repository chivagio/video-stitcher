<objective>
Turn the Phase 1 one-shot `preview` job into a paced, per-tick-drained preview **session**, and make pose/FOV actually move the render. This is the interactive spine: play/pause/scrub/frame-step/loop plus pan/zoom/FOV, all through the existing message-passing worker.

Purpose: RESEARCH Pitfall 2 — the current `WorkerCommand::Preview` runs the decode→render→present loop to completion, so commands queued during a preview (including `Intent`) sit in the channel until it ends. RESEARCH Pitfall 3 — `PoseControl::tick()` is never called and FOV never reaches `StitchPipeline::set_fov`, so pose intents have no visible effect today. Both must be fixed for PREV-02/PREV-04.
Output: `transport.rs` (pure, GPU-free state machine with tests), a reshaped session loop in `worker.rs`, the new transport/chrome commands and position/transport/pose events, and pose/FOV plumbing.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-04 | Denial of Service | `WorkerCommand::Seek { frame }` / `StepFrame { direction }` | high | mitigate | Type `frame` as `u64` and clamp it to `[0, total_frames]` inside the worker against the loaded `SourceInfo` before touching `FfmpegFileSource::seek`; reject `direction` values other than ±1 at the command boundary. An unbounded seek cannot reach the decoder. |
| T-02-05 | Denial of Service | `WorkerCommand::ResizeViewport` | medium | mitigate | Saturating `ViewportRect::for_chrome` clamps the rect; a zero/absurd size yields a non-drawable rect rather than an engine error or an allocation. |
| T-02-06 | Tampering | transport/pose event payloads | low | accept | `Position`/`Transport`/`Pose` carry only numeric values and a typed enum; there is no injectable text. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no dependency; package installs happen only in plan 02-05 behind the package-legitimacy checkpoint. |
