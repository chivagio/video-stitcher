| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-02-12 | Denial of Service | `SourceTileRenderer` resource creation | low | accept | The renderer is built once and cached on the shared device; a single extra pipeline cannot be amplified by repeated toggles (no per-toggle allocation). |
| T-02-13 | Information Disclosure | source-tile render output | low | accept | The source view renders only the operator's own decoded clips into the local surface; no network or cross-process path exists. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new dependency; all work uses `reco_core::wgpu` through the existing re-export (FOUND-04). |
