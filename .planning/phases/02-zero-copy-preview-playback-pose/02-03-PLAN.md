## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview → Rust | `set_presenter`/readback attach arguments are untrusted; presenter windows and surfaces are Rust-owned. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Elevation of Privilege / Spoofing | `WorkerCommand::SetPresenter` | high | mitigate | Type the argument as `PresenterKind` (no strings); presenter selection is not a security boundary but an invalid/unknown presenter must be impossible. The override only re-runs the probe chain and cannot inject a new surface. |
| T-02-08 | Tampering | readback frames over Tauri Channel | medium | mitigate | Display readback via `putImageData` on a canvas; do not widen the CSP (`img-src 'self' data:` stays; no `blob:`/`data:` image URLs, no `connect-src` widening). Keep `sourcemap: false`. |
| T-02-09 | Information Disclosure | presenter window/surface handles | high | mitigate | All window/surface creation stays in Rust; `surface()` never crosses IPC; new events carry only `PresenterKind` + an owned reason string. |
| T-02-10 | Denial of Service | readback cadence | medium | mitigate | A single `READBACK_FPS` throttle bounds readback IPC; the worker never blocks on the channel send (`let _ = channel.send(..)`). |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new crate or npm package in this plan; `WindowBuilder`/`Channel` come from the pinned `tauri =2.12.1` (unstable) already present. |
